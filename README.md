# Timber Market Intelligence (TMI) - Wisconsin

A mobile-friendly market intelligence platform for estimating timber stumpage values in North-Central Wisconsin.

## Features
- **Stumpage Calculator:** Calculates net value by subtracting harvesting and transportation costs from delivered mill prices.
- **Visual Analytics:** Real-time doughnut charts showing value distribution by species.
- **Local Storage:** All data remains on your device (browser-side).

## Usage
1. **Inventory:** Enter your forest composition (Species % and Acres).
2. **Market:** Enter current mill delivered prices.
3. **Analysis:** Adjust the harvesting cost slider to see your net estimated payout.

*Disclaimer: This tool provides estimates only. Actual harvest value depends on log quality, scaling, and market volatility.*
